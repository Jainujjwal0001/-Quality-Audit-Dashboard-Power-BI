📌 Project Overview

This project presents an interactive Quality Audit Dashboarddeveloped in Power BI to monitor organizational quality performance.It enables stakeholders to evaluate audit results, identify qualityissues, compare departments and managers, and track monthly trends usinginteractive dashboards.

🎯 Business Problem

Organizations perform regular quality audits to maintain operationalstandards. However, audit data is often scattered across multiplesources, making it difficult to monitor performance and identifyimprovement opportunities.
This dashboard provides a centralized reporting solution for: -Monitoring Quality Score - Tracking Error % and Defect % - ComparingDepartment, Manager, and Auditor performance - Analyzing monthly qualitytrends - Identifying top and low-performing employees
